Full-Stack Notes App

A full-stack notes application that lets users register, log in, and manage their personal notes.

Features

- User registration and login
- Create, view, update, and delete notes
- Persistent data storage
- Responsive interface
- Input validation and error handling

Only keep features that you have personally verified.

Tech Stack

- Frontend: HTML, CSS and JavaScript.
- Backend: Node.js, expressjs, mongoose, jsonwebtoken, bcryptjs.
- Database: MongoDB.
- Deployment: Netlify for the frontend; Render for backend.

Live Demo

"Open the Notes App" (https://fullstacknotesapp.netlify.app)

----------------------------------------

Run Locally

1. Clone this repository.
2. Install the frontend and backend dependencies separately.
3. Configure the required environment variables.
4. Start the backend and frontend using the commands defined in their respective package.json files.
